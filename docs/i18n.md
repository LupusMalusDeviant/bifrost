# Sprachen und Vorrang · Languages and precedence

Dieses Repository ist zweisprachig. Damit daraus keine zwei Wahrheiten über denselben
Betriebsablauf werden, gilt eine Regel — und sie steht auf **jeder** betroffenen Seite, nicht nur
hier.

This repository is bilingual. To keep that from producing two truths about the same operational
procedure, one rule applies — and it is printed on **every** affected page, not just here.

---

## Die Regel · The rule

> **Bei Widerspruch gilt die Fassung in der Ursprungssprache des Dokuments.** Sie steht in der
> Tabelle unten und im Kopf jeder Seite. Die abgeleitete Fassung ist eine Übersetzung, kein
> zweiter Vertrag.
>
> **On contradiction, the version in the document's source language wins.** It is named in the
> table below and in the header of every page. The derived version is a translation, not a second
> contract.

Das ist keine Höflichkeitsformel. Betriebsdokumentation wird unter Zeitdruck gelesen, und eine
Übersetzung hinkt jeder Änderung hinterher. Wer bei einem Widerspruch raten muss, welche Fassung
neuer ist, hat schon verloren.

This is not a politeness clause. Operational documentation is read under time pressure, and a
translation always lags a change. Anyone who has to guess which version is newer has already lost.

### Was zu tun ist, wenn die Fassungen auseinanderlaufen

1. Der Fassung in der Ursprungssprache folgen.
2. Ein Issue mit dem Label `docs` öffnen und **beide** Stellen nennen (Datei + Überschrift).
3. Die abgeleitete Fassung nicht "schnell reparieren", ohne die Ursprungsfassung gelesen zu
   haben — sonst entsteht eine dritte Variante.

### What to do when the versions diverge

1. Follow the version in the source language.
2. Open an issue labelled `docs` naming **both** places (file + heading).
3. Do not "quickly fix" the derived version without reading the source version first — that
   produces a third variant.

## Was ausdrücklich **nicht** übersetzt wird

**Die historischen ADRs bleiben deutsch.** Sie sind Zeitkapseln: Sie halten fest, was zu einem
bestimmten Datum mit dem damaligen Wissensstand entschieden wurde. Eine Übersetzung müsste bei
jeder Nachschärfung mitgezogen werden, und eine veraltete Übersetzung einer Entscheidung ist
schlimmer als gar keine — sie liest sich wie eine andere Entscheidung.

Eine vollständige ADR-Übersetzung ist **kein 1.0-Blocker**. Wer die Begründung einer Entscheidung
braucht, findet in `docs/en/` die betriebliche Folge; das *Warum* steht auf Deutsch daneben.

Dasselbe gilt für Lastenheft (`docs/prd/`), Pflichtenheft (`docs/plans/`) und die
Meilenstein-Verträge: interne Planungsdokumente, keine Betriebsanleitungen.

## What is deliberately **not** translated

**The historical ADRs stay German.** They are time capsules: they record what was decided on a
given date with the knowledge available then. A translation would have to be dragged along with
every refinement, and a stale translation of a decision is worse than none — it reads like a
different decision.

A full ADR translation is **not a 1.0 blocker**. If you need the reasoning behind a decision,
`docs/en/` carries the operational consequence; the *why* sits next to it in German.

The same applies to the requirements documents (`docs/prd/`), the implementation plans
(`docs/plans/`) and the milestone contracts: internal planning artefacts, not operating
instructions.

## Für Beitragende · For contributors

- **Ändert sich ein Betriebsablauf, ändert sich zuerst die Fassung in der Ursprungssprache.**
  Die abgeleitete Fassung darf im selben PR nachziehen oder in einem Folge-PR; sie darf nicht
  vorauslaufen.
- **Eine abgeleitete Fassung, die etwas behauptet, was in der Ursprungsfassung nicht steht, ist
  ein Fehler** — auch wenn die Behauptung stimmt. Dann gehört sie zuerst in die Ursprungsfassung.
- Neue englische Seiten ohne deutsches Original sind erlaubt und in der Tabelle als solche
  eingetragen. Sie sind dann selbst die Ursprungsfassung.

- **When an operational procedure changes, the source-language version changes first.** The
  derived version may follow in the same PR or a later one; it must not run ahead.
- **A derived version that states something absent from the source version is a bug** — even if
  the statement is true. It belongs in the source version first.
- New English pages without a German original are allowed and are marked as such in the table.
  They are then the source version themselves.
